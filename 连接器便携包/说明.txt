--------------------------------------------------------
一、这是什么
--------------------------------------------------------

让手机远程访问这台电脑上的 DeepSeek。

装上之后，你在电脑的 DeepSeek App 里开的会话，
手机上也能看、也能发消息，连 AI 的思考过程都是实时同步的。

适用场景：
  · 出门在外，用手机继续电脑上的对话
  · 躺着用手机聊天，不用坐到电脑前
  · 把二维码发给别人临时看某个会话


--------------------------------------------------------
二、怎么安装
--------------------------------------------------------

1. 把整个文件夹解压到任意位置（不要放在 C 盘根目录）
2. 双击「安装.bat」
3. 按提示操作，装完重启 DeepSeek

安装脚本会自动做：
  · 找到你的 DeepSeek 装在哪
  · 找到你这台电脑的局域网 IP
  · 安装连接器程序
  · 给 DeepSeek 打一个小补丁（可回滚）
  · 设置 3 个环境变量
  · 安装 DSH 插件
  · 配置开机自启 + 桌面快捷方式

不会动：你的会话记录、工作区文件、其它插件。


--------------------------------------------------------
三、怎么使用
--------------------------------------------------------

两个入口，功能完全一样：

  入口①  在 DeepSeek 左侧栏点「连接器」
  入口②  双击桌面「DSH连接器」图标（独立窗口）

推荐平时用入口①，因为不用切窗口。

操作流程：
  1. 点「内网」或「外网」
  2. 等二维码出来（内网 1 秒，外网 10-15 秒）
  3. 手机扫码，或者复制下面的链接
  4. 手机上就能看到当前会话


--------------------------------------------------------
四、功能介绍
--------------------------------------------------------

【内网 / 外网】

  内网：手机和电脑连同一个 WiFi 时用，速度快、不经过外网
  外网：手机用流量、或者不在同一个网络时用

  两个都点过也没关系，它们会同时开着，互不影响。


【三种过期策略】

  A · 长期有效
      扫一次之后链接一直能用，直到你手动点「停用」
      方便，但引擎会一直挂在公网上
      提示：界面上有红字警告，建议改用 B

  B · 拒绝新连接  （默认，推荐）
      5 分钟后二维码消失，并拒绝新的连接
      已经连着的手机不受影响
      适合日常使用：既限制了外泄窗口，又不打断正在用的设备

  C · 全部断开
      5 分钟后强制断开所有设备
      最严格，适合临时给陌生人看一眼


【两种通道模式】

  互斥：点内网就自动关外网，点外网就自动关内网
        始终只有一个二维码（默认，更安全）

  双通：内网和外网同时开，两个二维码并排显示
        适合一边在家里 WiFi、一边在外面用流量


【其它设置】

  显示方式    二维码 / 文本链接 / 两者都给
  有效期      二维码多久后消失，1-60 分钟
  停用        立刻断开所有已连接的设备
  自动开内网  连接器启动后自动恢复内网通道：引擎没开就先等 20 秒，就绪了再开；互斥模式下外网在跑就跳过


【重启后看到的状态是真实的】

  以前重启连接器，界面上的「外网」会显示成关闭，其实 cloudflared 还在跑、链接还能用。
  现在状态按「进程 + 隧道域名」还原：只要隧道活着，界面就显示外网在线并给出当前链接，
  按「停用」也是照着真实在跑的东西去关。

  同理，IP 变了不用重启 DeepSeek：重新生成一次链接、用新链接访问即可
  （登录凭据是绑在「访问地址」上的，换地址会重新发一份）。

【停用时会告诉你正在跑什么】

  点「停用并断开所有连接」前，会先列出当前真正在运行的通道：

    内网和外网都在运行
    · 内网  http://192.168.1.2:14925/?token=...
    · 外网  https://xxx.trycloudflare.com
    停止后，内网和外网通道上已连接的设备会立刻断开。
    确认停止吗？

  如果没有通道在跑，会直接告诉你"无需停用"，不会弹无意义的框。


--------------------------------------------------------
五、可能遇到的问题（都不是 bug）
--------------------------------------------------------

★★★ 问题 1：手机突然连不上了（最常见）

  症状：页面能打开，但一发消息就转圈 / 报错

  原因：电脑的局域网 IP 变了。
        换网络、换路由器、路由器重启后重新分配 IP，
        都会导致这个。
        但 DeepSeek 启动时记住的还是旧 IP，所以拒绝新 IP 的请求。

  解决：双击「重启DSH.bat」
        或者托盘右键退出 DeepSeek，再重新打开。

  怎么确认是不是这个原因：
        打开 DSH 连接器，看顶部状态。
        如果是引擎离线/连接异常，基本就是这个。


★★★ 问题 2：电脑有多个网卡，选了错的 IP

  症状：链接里的 IP 是 192.168.56.1 或 10.x.x.x 这类奇怪的地址，
        手机怎么都连不上。

  原因：电脑同时有 WiFi + 有线网 + 虚拟网卡（VMware、VirtualBox、
        Hyper-V、WSL 都会创建虚拟网卡）时，程序可能选错。

  解决：手动改一个文件：
        1. 打开 C:\Users\你的用户名\.dsh\connector\config.json
        2. 把 "lanIp" 改成正确的 IP
        3. 双击「重启DSH.bat」

  怎么查正确的 IP：
        按 Win+R，输入 cmd，回车，输入 ipconfig
        找 "IPv4 地址" 里那个跟你路由器同网段的
        （通常是 192.168.1.x 或 192.168.0.x 或 10.0.0.x）

  安装时怎么看有没有选错：
        安装脚本会把所有候选 IP 都打印出来，
        如果你看到多个，就要留意它选了哪个。


★★ 问题 3：DeepSeek 升级后失效

  症状：界面看着正常，但手机连不上。

  原因：DeepSeek 升级会覆盖我们改过的文件，
        导致端口变回随机、token 文件不再更新。

  解决：双击「检查补丁.bat」，它会重新打补丁并告诉你结果。


★★ 问题 4：外网链接过一段时间就不能用了

  症状：昨天保存的外网链接，今天打不开。

  原因：外网用的是 Cloudflare 临时隧道，
        每次重建都会换一个新域名（这是它的机制，不是我们能做到的）。

  解决：重新点一次「外网」，会生成新链接。
        内网链接不受影响（IP 不变就一直有效）。


★ 问题 5：二维码显示"已过期"

  这不是错误。三种策略都会让二维码在设定时间后消失，
  目的是减少别人拍照转发的机会。

  需要重新用，再点一次「内网」或「外网」即可。


★ 问题 6：手机上能看，但发不了消息

  说明同一时刻只能一端发消息。
  如果电脑那边正在生成回复，手机发送会被拒绝。

  等电脑那边回复完，手机上就能发了。
  两头交替使用是完全正常的。


★ 问题 7：手机端页面越来越卡

  原因：当前会话的消息太多（几千条），浏览器渲染压力大。

  解决：开一个新会话聊新话题。
        历史会话随时可以回去看，不会丢。


★ 问题 8：关掉 DSH 连接器窗口，手机还连着

  这是故意的设计，不是没生效。

  想真正断开，点界面上的「停用并断开所有连接」。


★ 问题 9：DeepSeek 没开的时候，左边看不到「连接器」

  插件是装在 DeepSeek 里的，DeepSeek 没启动自然看不到。

  这时候用桌面的「DSH连接器」独立窗口，
  它还能显示「启动 DeepSeek」按钮。


★ 问题 10：刚点完外网，扫码打不开

  原因：新域名需要 30 秒左右在全世界生效（DNS 传播）。

  解决：等半分钟再扫，或者再点一次「外网」。

六、文件说明
--------------------------------------------------------

  安装.bat          一键安装
  卸载.bat          一键卸载（清理干净）
  检查补丁.bat      DeepSeek 升级后跑一次
  重启DSH.bat       手机连不上时跑一次
  说明.txt          本文件

  scripts\          实际的安装/卸载逻辑，懂技术的可以看
  files\connector\  连接器程序本体
  files\plugin\     DeepSeek 插件本体


--------------------------------------------------------
七、怎么卸载
--------------------------------------------------------

双击「卸载.bat」，会清理：
  · 连接器程序
  · DeepSeek 插件
  · 3 个环境变量
  · 开机自启
  · 桌面快捷方式
  · 还原 DeepSeek 的原始文件

不会动你的会话记录和工作区。


--------------------------------------------------------
八、安全提醒
--------------------------------------------------------

外网通道会把这台电脑的 DeepSeek 暴露在公网上，
靠随机域名 + token 保护。

建议：
  · 不用的时候点「停用」
  · 平时用 B 策略（默认就是）
  · 不要把外网二维码发给不信任的人
