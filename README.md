# 破甲后双端互联

让手机（同一 WiFi 或 4G）远程访问**桌面 DeepSeek App** 的会话，实现实时同步——包括 AI 的思考过程。

> ⚠️ 本项目面向**已完成破甲**的 DSH 环境。未破甲的 DSH 装不上这里的插件。

## 为什么这样设计

普通的"手机连 web 实例"方案做不到同步，因为：

```
桌面 App 的引擎（进程 A）  ← 有自己的一份事件流
dsh web 实例（进程 B）     ← 有另一份事件流
```

两个进程各跑各的，UI 只渲染自己内存里的事件。**共享磁盘文件 ≠ 共享事件流**。

所以本项目的做法是：**让手机连上桌面 App 自己的那个引擎**，而不是另起一个。

```
手机（WiFi / 4G）
   ├─ 内网：192.168.1.2:14925 ──┐
   └─ 外网：xxx.trycloudflare.com
          └─ 隧道 → 127.0.0.1:14926（改写代理）
                └────────────────┴──→ 127.0.0.1:14925
                                          ↑
                              桌面 App 的引擎（同一个进程）
```

因为连的是同一个进程、同一路 `$events`，所以手机发的消息电脑立刻能看到，思考过程也是逐字同步。

## 核心组件

| 组件 | 作用 | 端口 |
|---|---|---|
| `server.mjs` | 连接器本地 API、通道管理、版本契约 | 14930 |
| `DSH连接器.hta` | 桌面控制面板（独立窗口） | — |
| `dsh-port-forward.mjs` | 局域网 TCP 转发（带准入检查） | 14925 |
| `dsh-rewrite-proxy.mjs` | 外网改写代理（HTTP + WebSocket） | 14926 |
| `client.js` | DSH 插件界面（React + slots） | — |

**为什么要一个"改写代理"**：DSH 引擎的 `/api` 有 browser-trust fence，只信任 `--trusted-host` 声明的 authority。隧道域名每次都变，代理把进来的 `Host`/`Origin` 统一改写成已声明的 `192.168.1.2:14925`，从而放行。副作用是内网/外网的 cookie 完全共用，切换网络不用重新登录。

## 功能

**连接器**
- 内网 / 外网通道切换
- 二维码（单通道 / 双通并排）+ 文本链接
- 三种过期策略：A 长期有效 / **B 拒绝新连接（默认）** / C 全部断开
- 两种通道模式：互斥（一个二维码）/ 双通（两个并排）
- 停用前**列出真实在跑的通道**再确认
- 引擎离线时一键拉起 DeepSeek

**插件**
- 与 HTA 功能对齐，嵌在 DSH 左侧栏
- 零前端依赖（二维码直接用 `<img>` 指向程序）

## 已知限制

1. **IP 变化后需重启 App**：`--trusted-host` 是启动参数，IP 变了要重启才生效。
2. **外网域名每次都变**：Cloudflare quick tunnel 机制。要固定域名需 Tailscale 或命名隧道。
3. **同一会话同时只能一端写**：DSH 的 writer 锁，按轮次交替。
4. **插件不能启动 DeepSeek**：DSH 没开就看不到插件。HTA 有【启动 DeepSeek】按钮。

## 踩过的坑（重要）

详细记录见 [`项目交接-20261116.md`](项目交接-20261116.md) 第六节。最致命的三个：

| 坑 | 后果 |
|---|---|
| PowerShell 的 `Set-Content -Encoding UTF8` 会写 BOM | DSH 的 `JSON.parse` 抛错 → **App 完全打不开** |
| 脚本文件缺 BOM | PS 5.1 按 GBK 读 → 中文引号被吃掉 → 语法错误 |
| `ELECTRON_RUN_AS_NODE=1` 被继承 | 拉起的 DeepSeek 变成无窗口的 Node 进程 → 永远等不到端口就绪 |

**记住**：给 PS 读的脚本要 **UTF-8 with BOM**，给 DSH 读的 JSON 要 **UTF-8 without BOM**。
